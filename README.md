\# Online Fitness Tracking Application



A web-based fitness tracking application that helps users log workouts, set fitness goals, monitor progress, and participate in fitness challenges.



\## Technologies Used



\* Frontend: React.js, JavaScript, Tailwind CSS, Vite

\* Backend: Java, Spring Boot, Maven

\* Database: MySQL



\## Project Structure



\* `frontend/` — React frontend

\* `backend/` — Java Spring Boot backend

\* `database/` — SQL database files



\## Requirements



\* Node.js and npm

\* Java JDK

\* MySQL



\## How to Run



\### Frontend



Open a terminal in the `frontend` directory and run:



`npm install`



`npm run dev`



\### Backend



Configure the MySQL database connection, then open a terminal in the `backend` directory and run:



`.\\mvnw.cmd spring-boot:run`



\### Database



Import `database/fitness\_tracker.sql` into MySQL.
