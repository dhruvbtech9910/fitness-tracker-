\# Online Fitness Tracking Application



A web-based application that allows users to record workouts, set fitness goals, monitor progress, and participate in fitness challenges. Administrators can manage users and fitness content.



\## Technologies Used



\* Frontend: React.js, JavaScript, Tailwind CSS, Vite

\* Backend: Java, Spring Boot, Maven

\* Database: MySQL



\## Project Structure



\* `frontend/` – React frontend

\* `backend/` – Java Spring Boot backend

\* `database/` – SQL database files



\## Requirements



\* Node.js and npm

\* Java JDK

\* MySQL



\## Setup Instructions



\### 1. Database



Import `database/fitness\_tracker.sql` into MySQL and configure your database connection in the backend.



\### 2. Backend



Open a terminal in the `backend` folder and run:



`.\\mvnw.cmd spring-boot:run`



\### 3. Frontend



Open a terminal in the `frontend` folder and run:



`npm install`



`npm run dev`
